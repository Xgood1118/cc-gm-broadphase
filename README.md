# 宽相碰撞检测

一个用排序扫掠做宽相、并保证不漏对的碰撞候选生成器。仅依赖 Python 标准库。

## 保留签名

- `AABB`（dataclass：`id`, `lo`, `hi`，维度任意，零尺寸合法）
- `sweep_prune(boxes)`：构造即完成全量排序；`pairs()` 生成候选对；`move(id, lo, hi)` 增量更新；`add(box)` 局部插入
- `pairs(self)`：返回 `[(i, j), ...]`，`i < j`，按字典序排序
- `verify_brute(boxes)`：暴力两两比对，返回同样的规范形式

## 排序规则

- 扫掠轴为第 0 轴，排序键为 `(lo[0], id)`：**同起点按编号升序**，与传入顺序无关，结果确定。
- 扫描时维护按该键排序的序列，对每个盒子只检查第 0 轴仍可能相交（`b.lo[0] <= a.hi[0]`）的后继，之后直接剪枝；命中者再做全轴重叠检查。
- 重叠按**闭区间**判定：边界相触（`lo == hi`）算重叠。

## 增量更新

- `move(id, lo, hi)` 只把被移动的盒子从有序序列摘除并局部重插（一次 `bisect` 定位），不做全量重排。
- 计数器用于证明这一点：
  - `last_sort_scans`：最近一次排序维护放置的元素数。全量构建 = n，增量移动 = 1。
  - `last_scans`：最近一次 `pairs()` 的第 0 轴检查次数（含剪枝那次），上界为 `n*(n-1)/2`。
- 增量结果与全量重建、暴力比对完全一致（见测试 `test_incremental_matches_full_rebuild`）。

## 边界情况

- **零尺寸盒**（`lo == hi`）：按点处理，落在其他盒内即算一对。
- **完全重合盒**：同起点按编号定序，两两成对，结果确定。
- **单物体**：`pairs()` 返回 `[]`。

## 实测（`data/boxes.json`，3 个盒子）

`python -m broadphase.cli data/boxes.json --out pairs.json` 输出：

| 指标 | 值 |
| --- | --- |
| 候选对数 | 1 |
| 暴力对数 | 1 |
| 扫描次数（`last_scans`） | 3 |
| 最大重叠对数（第 0 轴最大同时重叠深度 2，C(2,2)） | 1 |

候选与暴力完全一致（`match_brute: True`）。最大重叠对数定义为第 0 轴扫掠最大深度 `d` 的 `d*(d-1)/2`。

## 自测

```
python -m pytest tests -q
python -m broadphase.cli data/boxes.json --out pairs.json
```

测试覆盖：候选与暴力一致、稳定排序（同起点按编号）、增量与全量重建一致、重合与零尺寸、扫描次数（增量非全排、剪枝有效）、重复运行结果一致。
